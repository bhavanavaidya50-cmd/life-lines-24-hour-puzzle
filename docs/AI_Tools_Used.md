#### C. Audio Engineering (Web Audio API)
- Formulated programmatic frequency arrays, envelope ramps, and LFO modulation parameters to produce mature procedural ambience, chimes, and UI feedback without requiring external copyrighted audio assets.

#### D. Quality Assurance & Test Scripting
- Authored the headless automated test suite (`tests/engine_test.js`), generating 66 automated test assertions verifying game engine rules across all five scenarios.
